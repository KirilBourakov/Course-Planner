# Course-Planner

TLDR: a website that helps students keep track of degree and course requirements, and plan courses to take. bascially what course advisors currently do. (the advisors will probably like that this helps them so we might ask them for input.)

Longer Summary

Basically
its a web app that will help students plan their 4 years, by like making sure they have all their requirements for the degree and for the courses they want to take. right now we use course advisors for that, but an app would be more helpful and available all the time.

Where to Get The Data
a lot of the information about what the course and degree requirements are are public and online, so we can get that data manually or scrape it.

Target Users
we are thinking of making it only for UNB at first (there's a Waterloo version thats waterloo only i think, but you have to download it its not a web app). but it would be good to keep the possibility of making this generally applicable to any university in the back of our mind.
